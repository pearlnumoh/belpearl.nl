# Belpearl.nl

Statische one-page website (`index.html`) voor belpearl.nl, gehost via GitHub Pages vanaf `main`.

## Werkafspraken

- **Pull requests en samenvoegen:** maak na afgeronde wijzigingen zelf een pull request naar `main` en voeg die direct samen. Niet eerst om toestemming vragen.
- Communiceer in het Nederlands.

## Structuur

- `index.html`: alle HTML en CSS
- `assets/images/`: afbeeldingen in AVIF, WebP en JPEG, in meerdere breedtes (gebruikt via `<picture>` met `srcset`)
- `CNAME`: eigen domein voor GitHub Pages
